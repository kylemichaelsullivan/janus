# Accessibility

Web is gated by Axe. Native cannot run axe-core.

## Web

- `axe-core`, `vitest-axe`, and `@axe-core/playwright`
- WCAG 2.2 AA
- Serious and critical violations fail CI

## Native

- Mapping tests prove ARIA → RN accessibility props
- React Native Testing Library a11y queries
- AMA (`@react-native-ama`) in `__DEV__` on Expo apps

Do not invent `@axe-core/react-native`. Axe DevTools Mobile is optional and licensed; it is not a `1.0.0` blocker.

Every new layer ships its Axe or RNTL assertion in the same change.
