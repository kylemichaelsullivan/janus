# janus add

When the user wants a UI component, run `janus add <name>` (button, input, dialog, tabs, …). The file is copied into `src/components/ui`. Customize the copy. Do not paste upstream ShadCN / Radix / Base UI source unchanged. Primitives and headless stay as dependencies.
